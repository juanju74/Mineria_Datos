## Cómo correr el análisis

1. Instalar dependencias:
```bash
pip install pandas numpy matplotlib scikit-learn jupyter
```

2. Abrir el notebook:
```bash
cd trabajo_reproducible
jupyter notebook analisis_portuario.ipynb
```

3. Click en **Ejecutar todo** — el CSV ya está en la misma carpeta, no hay que configurar nada.
